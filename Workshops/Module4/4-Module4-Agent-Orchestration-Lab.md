# Module 4 - Agent Orchestration: Build Your AI Dream Team Hands-On Lab

Please follow the instructions below to complete the second hands-on lab for Module 4.

_Use GitHub Copilot CLI to coordinate a prebuilt team of specialist agents that plan, design, build, validate, and hand off a small static dashboard._

## Welcome

- **Who is this for**: Developers who have basic GitHub and GitHub Copilot familiarity and want to coordinate specialist agents from the terminal.
- **What you'll learn**: How to inspect custom agents, ask an Orchestrator to involve a Planner, separate design and coding work, validate generated output, and produce a final handoff.
- **What you'll build**: Mona's Project Pulse dashboard, a small static app with HTML, CSS, JSON data, a VS Code launch configuration, and a final orchestration handoff.
- **Local prerequisites**:
  - Completed [Create Applications with the Copilot CLI](https://github.com/martinpolivka/skills-create-applications-with-the-copilot-cli) exercise.
  - GitHub Copilot CLI installed and authenticated with an account that has a GitHub Copilot licence.
  - Access to the prepared workshop repository.
- **How long**: This exercise takes less than one hour to complete.

In this exercise, you will:

1. Inspect the prebuilt custom agent team in `.github/agents/`.
1. Use GitHub Copilot CLI as the orchestration interface.
1. Ask the Orchestrator to involve Planner, Designer, and Coder agents for a Project Pulse dashboard.
1. Build and validate a small static dashboard with `app/index.html`, `app/styles.css`, and `app/project-data.json`.
1. Produce a final Orchestrator handoff that summarises validation and remaining follow-up.

### How to start this exercise

Use the prepared workshop repository. Do not copy, fork, or create a new repository from the GitHub Skills template.

[Open the prepared Module 4 agent orchestration lab repository](https://github.com/martinpolivka/skills-agent-orchestration-build-your-ai-dream-team)

Before making any changes, create your own branch from `main`. Use a branch name that identifies you, for example `participant/<your-name>`.

Work only on your own branch during the lab. The repository is already prepared for the workshop, so start working from your branch immediately.
